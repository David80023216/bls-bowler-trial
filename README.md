# BLS Bowler Stats — Trial Preview

A trial page for the BLS bowler stats app: find your bowling center, tap
your name, and your current average / high game / high series from BLS are
already loaded. Pre-loaded with a real sample league (Women's Classic
2026-27, Ashwaubenon Bowling Alley). Anything imported in this trial is
saved only in the visitor's own browser.
